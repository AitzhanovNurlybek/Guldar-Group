# Плавающие кнопки связи

Проверка 28 октября 2026 года. Пользователь предложил взять принцип кнопок с [Airis Residence](https://airisresidence.kz/).

## Решение

Пример проверен в браузере на ширинах 390 и 1440 px. На телефоне у Airis есть постоянная нижняя панель с быстрыми действиями, на компьютере кнопки связи закреплены справа снизу. Для GulDar адаптирован этот принцип с фирменной палитрой и двумя действиями компании.

- На телефоне панель видна с первого экрана и остаётся при прокрутке услуг, писем и интерактивных блоков. Подписи «Позвонить» и «WhatsApp» читаются целиком, без угадывания по одному значку.
- WhatsApp использует оранжевую заливку и белый текст, звонок светлую поверхность и контур. Высота кнопок 52 px, размер текста 15 px. Округлая форма локально повторяет заданный пример; общий стиль сайта сохранён.
- На компьютере справа снизу находятся иконка звонка и расширенная кнопка WhatsApp с подписью. Иконка имеет доступное имя и подсказку.
- Во время ввода в текстовое поле и при открытом меню панель скрывается. После завершения возвращается. Прежняя логика скрытия над разделами удалена; компонент не требует JavaScript для отображения и переходов.
- При увеличении текста до 200% кнопки перестраиваются в две широкие строки, сохраняя целые подписи. Учтены safe area, запас в конце страницы и нижний отступ прокрутки.
- Повторная ссылка звонка на первом экране убрана, поскольку звонок доступен в панели. Сокращённая главная и формы по раскрытию сохранены.

| `npm run test:e2e` | 164/164 PASS |
| Адаптивность | 10 страниц × 14 ширин, 320–1920 px, без горизонтального переполнения |
| Постоянная видимость | Первый экран, услуги, письма и этапы на 320, 390, 768, 1440 px |
| Узкий экран | На 320 px обе подписи помещаются в одну строку, кнопки по 135 × 52 px |
| Увеличенный текст | 200%, подписи целые, последний текст подвала выше панели |
| Клавиатура | Видимый фокус, сплошная обводка 3 px |

| Светлая схема | Тёмная ОС и Chromium Auto Dark, PASS |
| Скан `avoid-ai-design` | 42 файла, 0 замечаний |

Адреса действий проверены: звонок ведёт на `tel:+77056117474`, WhatsApp на существующий номер компании `77786812931` с подготовленным приветствием. Текст, телефон и сообщения не меняются при прокрутке. Прежние сценарии калькулятора, выбора, писем, 3D, ошибок и повторной загрузки прошли.

Скриншоты первого экрана и разделов просмотрены на телефоне и компьютере. Проверки выполнены в Chrome с эмуляцией размеров; физические телефоны и отдельный Safari не проверялись.
