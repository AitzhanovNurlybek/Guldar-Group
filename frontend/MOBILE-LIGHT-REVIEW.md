# Светлая мобильная версия

Проверка 28 октября 2026 года после обращения о Samsung Internet.

## Причина и исправление

Пользователь подтвердил включённую «Версию для ПК» на Samsung. На опубликованной странице уже был корректный viewport `width=device-width, initial-scale=1, viewport-fit=cover`; широкий уменьшенный вид на присланном скриншоте связан с выбранным режимом браузера. Для обычного мобильного масштаба этот режим нужно выключить. Сайт не меняет настройки браузера пользователя и не блокирует увеличение пальцами.

До исправления в HTML отсутствовал ранний `color-scheme`, а CSS объявлял `light` без `only`. Автоматическое затемнение воспроизведено через Chromium DevTools Protocol: светлая страница становилась чёрной. Теперь viewport объявляет `colorScheme: "only light"`, CSS использует `color-scheme: only light`, а body получает явный фон. Этот способ отказа от автоматического затемнения описан в [Chrome Developers](https://developer.chrome.com/blog/auto-dark-theme).

На ширинах до 1023 px фон белый, подложки светло-серые #f2f5f7. Основная услуга и главное рекомендательное письмо тоже получили светлые поверхности. Для текста используются #172f3e, #2e4553 и #405663. Описание первого экрана сохраняет 17 px, подписи 14–15 px. Второстепенная ссылка расчёта увеличена до 16 px. Кнопка WhatsApp остаётся контрастной, отступ над содержимым первого экрана немного сокращён.

## Проверки

| Проверка | Результат |
| --- | --- |
| `npm run build` | PASS, TypeScript и 16 страниц/ресурсов |
| `npm run lint` | PASS |
| `npm run test:e2e` | 160/160 PASS |
| Матрица адаптивности | 10 страниц × 14 ширин, 320–1920 px, без горизонтального переполнения |
| Тёмная ОС и Chromium Auto Dark | 360, 384, 412, 430 px: фон остаётся светлым |
| Начальный масштаб | 1:1, innerWidth совпадает с шириной эмулируемого устройства |
| Увеличение текста | Главная и контакты, 390 px, 200%, PASS |
| Меню, формы и 3D | Прежние сценарии, фокус, Escape, ошибки и повторная попытка, PASS |

В постоянный браузерный прогон добавлена проверка `mobile keeps readable light colours in dark OS and Chromium Auto Dark`. Она проверяет раннее объявление схемы, начальный масштаб, отсутствие запрета на увеличение и сравнивает реально отрисованный участок фона до и после включения Auto Dark. Сравнение всего PNG с текстом не используется: сглаживание букв может давать небольшие различия без изменения цвета фона.

Контраст мобильного описания на белом фоне 10,04:1, на подложке 9,17:1; подписи на подложке 7,03:1. Контраст границы поля на подложке 3,52:1. Оранжевая кнопка с белым текстом сохраняет 5,10:1.

## Ограничение Samsung Force Dark

Проверки выполнены в установленном Chrome с мобильной эмуляцией и включённым Chromium Auto Dark. Подстановка Samsung User Agent не заменяет физический Samsung Internet; проверки на реальном Samsung в этой сессии не выполнялись.

Samsung описывает отдельный принудительный Force Dark, который в некоторых версиях может игнорировать настройки сайта. Если после обновления страницы фон остаётся тёмным, нужно отключить принудительное затемнение веб-содержимого либо выбрать использование темы сайта в настройках Samsung Internet. Название пункта зависит от версии. Подробности и ответы команды браузера: [Samsung Developer Forums](https://forum.developer.samsung.com/t/detail?id=5283). Код сайта не обещает обход этого принудительного режима.
