## Исправления

- Пустой блок результата теперь содержит собственное изображение `/scene/d/144.avif`. Модель в hero находится в обычном блоке страницы, без фиксированного слоя с отрицательным z-index.
- Родитель каждого `Image fill` позиционирован. Постер использует `picture` с мобильным источником; готовые AVIF/WebP отдаются напрямую, без перекодирования каждого выбранного кадра на сервере.
- Lenis и GSAP удалены. Прокрутка нативная; обработчики объединяются в requestAnimationFrame. Цикл останавливается, когда нет активных анимаций.
- На сенсорных устройствах, экранах до 1023 px, при reduced motion и на слабых устройствах используются изображения. Ручной выбор этапа сохраняется при прокрутке.
- Рендер WebGL останавливается после завершения смены этапа, вне экрана и в скрытой вкладке; предел — 60 кадров/с. Проверка неподвижного состояния подтверждает отсутствие новых отрисованных кадров.
- Формы загружаются через IntersectionObserver без постоянного ожидания остановки прокрутки. У загруженных форм убрана искусственная минимальная высота. Калькулятор показывает итог сразу.
- Убраны мобильный параллакс, магнитные кнопки, декоративный курсор, инерция бокового меню и бегущая строка. Сетка больше не использует шумовой SVG-фильтр.
- Исправлены длинные заголовки услуг, размеры кнопок и полей, порядок изображения и контролов, доступность ползунка и прокрутка меню. Шапка остаётся доступной на телефоне.
- Фон и панели стали светлее; услуги и готовый результат получили светлые секции. Основные цветовые пары проверены вычислением, контраст 6,24:1 и выше.

## Backend

Страницы не обращаются к FastAPI; формы готовят сообщения WhatsApp. Причина задержек прокрутки находилась в клиентских эффектах. Для существующих обработчиков без блокирующего ввода-вывода использован `async def`, кэширование CORS preflight увеличено до 3600 секунд. Для `/scene/` настроен HTTP-кэш. Нагрузочный тест опубликованного API не проводился. Существующий `/api/leads` остаётся заготовкой без сохранения в БД; новых обещаний отправки заявки через него в интерфейсе нет.
