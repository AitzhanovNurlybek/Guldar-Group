# Frontend — сайт GulDar Group

Сайт ТОО «GulDar Group» (Алматы): ремонт и обслуживание коммерческих помещений, металлоконструкции, поставка электротехники и стройматериалов.

**Статус:** дизайн и тексты готовы, данные собраны из открытых источников (satu.kz, 2GIS, uchet.kz). Всё, что нужно подтвердить у заказчика, помечено `TODO` в `src/lib/site.ts`.

Все заявки ведут в WhatsApp: кнопки на каждой услуге, плавающая кнопка на телефоне и конструктор сообщения «Давайте обсудим» (главная и контакты).

## Стек

Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · three.js + @react-three/fiber (3D-стройка на фоне)

## Запуск

```bash
cd frontend
npm install
cp .env.example .env.local   # заполнить значения
npm run dev                  # http://localhost:3000
```

Другие команды: `npm run build` — сборка, `npm run lint` — проверка кода.

## Что куда загружать

| Что | Куда положить | Где подключить |
|---|---|---|
| Контакты, услуги, цены, клиенты | — | `src/lib/site.ts` |
| Номер WhatsApp | — | `site.whatsapp` в `src/lib/site.ts` (только цифры, `77786812931`) |
| Фото объектов (jpg/webp, от 1600 px по ширине) | `public/photos/` | массив `projects` в `src/lib/site.ts` — блок «Объекты» появится сам |
| Своя 3D-модель вместо стройки на фоне (`.glb`, до ~3 МБ) | `public/models/` | `backgroundModel` в `src/lib/site.ts`, например `"/models/building.glb"` |
| Логотип в векторе (SVG) | — | заменить знак в `src/components/Logo.tsx` и `src/app/icon.svg` |

Модель подгоняется по размеру автоматически и так же вращается при прокрутке. Если файла нет или он битый, останется стройка, нарисованная кодом, и сайт не сломается.

## Дизайн

- Строительный стиль: синий из логотипа (`#195177`, `#6d94ae`) + сигнальный оранжевый `#f5871f`, узкий шрифт Oswald заглавными для заголовков и кнопок, прямые углы, сигнальная лента, миллиметровка на фоне. Токены — `src/app/globals.css`.
- 3D на фоне всего сайта (`src/components/three/ConstructionScene.tsx`): башенный кран и две башни из логотипа. Прокрутка = ход стройки: сцена поворачивается, этажи растут, фасад догоняет каркас, кран носит груз наверх; внизу страницы здание готово.
- Производительность: сцена рисуется только во время прокрутки (`frameloop="demand"`), в покое GPU не нагружается; геометрия — несколько InstancedMesh, без тяжёлых материалов. При «уменьшить движение» в системе стройка меняется без плавной анимации.
