# Frontend — сайт GulDar Group

Сайт ТОО «GulDar Group» (Алматы): ремонт и обслуживание коммерческих помещений, металлоконструкции, поставка электротехники и стройматериалов.

**Статус:** дизайн и тексты готовы, данные собраны из открытых источников (satu.kz, 2GIS, uchet.kz). Всё, что нужно подтвердить у заказчика, помечено `TODO` в `src/lib/site.ts`.

Все заявки ведут в WhatsApp: кнопки на каждой услуге, плавающая кнопка на телефоне и конструктор сообщения «Давайте обсудим» (главная и контакты).

## Стек

Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · three.js + @react-three/fiber (3D-макет помещения на фоне)

## Запуск

```bash
cd frontend
npm install
cp .env.example .env.local   # заполнить значения
npm run dev                  # http://localhost:3000
```

Другие команды: `npm run build` — сборка, `npm run lint` — проверка кода.

## Что куда загружать

| Что | Куда положить | Где подключить |
|---|---|---|
| Контакты, услуги, цены, клиенты | — | `src/lib/site.ts` |
| Номер WhatsApp | — | `site.whatsapp` в `src/lib/site.ts` (только цифры, `77786812931`) |
| Фото объектов (jpg/webp, от 1600 px по ширине) | `public/photos/` | массив `projects` в `src/lib/site.ts` — блок «Объекты» появится сам |
| Своя 3D-модель вместо макета на фоне (`.glb`, до ~3 МБ) | `public/models/` | `backgroundModel` в `src/lib/site.ts`, например `"/models/building.glb"` |
| Логотип в векторе (SVG) | — | заменить знак в `src/components/Logo.tsx` и `src/app/icon.svg` |

Модель подгоняется по размеру автоматически и так же вращается при прокрутке. Если файла нет или он битый, останется макет, нарисованный кодом, и сайт не сломается.

## Дизайн

- Синий из логотипа (`#195177`, `#6d94ae`) + сигнальный оранжевый `#f5871f`, шрифт Manrope, короткие тексты, сигнальная лента как акцент. Токены — `src/app/globals.css`.
- Панель слева на десктопе свёрнута в иконки и раскрывается кнопкой поверх контента (закрывается кнопкой, Esc или кликом мимо). На телефоне — меню из верхней панели.
- 3D на фоне всего сайта (`src/components/three/RenovationScene.tsx`): коммерческое помещение в разрезе, «до» и «после» ремонта. Прокрутка = ход ремонта: валик красит стену, кладётся плитка, вешаются и загораются светильники, ставится витрина, появляются стойка, стеллаж и вывеска с логотипом. Макет поворачивается при прокрутке.
- Производительность: рендер по требованию (`frameloop="demand"`). На первом экране — лёгкое покачивание ~30 к/с, ниже — кадры только во время прокрутки. При системной настройке «уменьшить движение» покачивания и наклона за курсором нет.

## Структура

```
src/

    page.tsx              главная
    uslugi/               услуги и цены
    produkciya/           поставка материалов

    ...                   Logo, Icons, ServiceCard, Reveal, Footer
  lib/site.ts             все данные сайта — править здесь
```
