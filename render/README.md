# Фото-рендер фона сайта

Фон сайта — не 3D в браузере, а заранее отрендеренные в Blender кадры: коммерческое помещение в разрезе
от черновой коробки до готового интерьера. Прокрутка страницы листает кадры, как видео
(`frontend/src/components/scene/SceneFrames.tsx`).

## Сюжет (прогресс прокрутки 0 → 1)

| Прогресс | Что происходит |
|---|---|
| 0 | черновое помещение: кирпич, бетонная стяжка, прожекторы на треногах, лампочки, инструмент, мусор, плёнка на витрине |
| 0.06–0.30 | стены: штукатурка и покраска поднимаются снизу вверх, слева синяя фирменная стена |
| 0.30–0.48 | пол: полированный бетон расходится из дальнего угла, инвентарь убирают по мере прохода кромки |
| 0.48–0.62 | электрика и свет: опускаются светильники и споты, стройсвет гаснет |
| 0.60–0.68 | витрина: снимают плёнку, ставят стекло |
| 0.66–0.90 | стойка, стеллаж с товаром, зона отдыха, островная витрина, зелень |
| 0.86–0.96 | загорается вывеска GulDar Group |

Фронт работ — светящаяся оранжевая кромка (цвет бренда). Пороги этапов продублированы
в подписи этапа на сайте (`SceneBackground.tsx`, `STAGES`).

## Как пересобрать

Нужны Blender 4.2+ (проверено на 5.2 LTS) и Python с Pillow.

```bash
python render/fetch_assets.py            # CC0-ассеты Poly Haven → ~/render-cache/guldar (вне OneDrive, ~200 МБ)
blender -b --factory-startup -P render/scene.py -- --test          # пробные кадры: 0, 0.2 … 1 (50 %)
blender -b --factory-startup -P render/scene.py -- --render        # все 144 кадра (GTX 1650 + CUDA: ~25 с/кадр)
python render/export_frames.py           # PNG → AVIF в frontend/public/scene/{d,m} + WebP-постеры
```

Параметры `scene.py`: `--frames 1-144`, `--res 100`, `--samples 128`, `--floor <текстура>`, `--device CUDA|OPTIX`.
OptiX на драйвере NVIDIA 551 не компилируется — по умолчанию CUDA.
